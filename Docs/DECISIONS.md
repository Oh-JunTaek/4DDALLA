## 3. 핵심 위험

- 공식 채널 미발견 및 허용된 수집 경로 부족
- 프랜차이즈 매장 제외 조건 누락·OCR 오류
- 매장 정보 공급자의 캐시·저장·표시·AI 처리 제한
- 검수 대기량 급증 및 운영자 부담
- 로컬 PC 미가동 기간의 데이터 노후화
- 사이트 구조 변경·요청 제한·호출량 초과
- 광고·커뮤니티 기능 확대 시 운영·법률 부담 증가

## 4. 변경 관리

기술 결정 변경은 기존/신규 값, 변경 이유, 영향받는 문서·DB/API·테스트, 버전 호환성, 승인자, 승인 일자를 기록한다. **미정 항목을 코딩 에이전트가 독자적으로 확정하지 않는다.**
